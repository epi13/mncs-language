# Specification Status

Documents in this directory describe the emerging normative semantic model. They are incomplete and may change incompatibly before a versioned language specification exists.

Normative terms such as **MUST**, **SHOULD**, and **MAY** indicate intended requirements for the current research model, not a claim of standards-body status.
